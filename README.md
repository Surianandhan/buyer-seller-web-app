# Buyer Seller Web Application

A frontend-based web application developed as part of a Software Engineering project, featuring separate interfaces for buyers and sellers.

## Features

- Role-based navigation (Buyer / Seller)
- Separate interfaces for buyers and sellers
- Basic login flow simulation
- Interactive UI using JavaScript
- Clean and responsive design

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

Website/
│
├── index.html        → Landing / login page  
├── buyer.html        → Buyer interface  
├── seller.html       → Seller interface  
├── buyer.js          → Buyer logic  
├── seller.js         → Seller logic  
├── login.js          → Login handling  
├── style.css         → Styling  

## How to Run

1. Open `index.html` in any browser  
2. Navigate as Buyer or Seller  
3. Interact with the UI  

## Limitations

- No backend integration  
- No real authentication  
- No database connectivity
